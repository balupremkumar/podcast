NZ
Health Sector Context

Voice recordings processed by this pipeline are biometric PHI under the NZ Health Information Privacy Code 2020. The fully local architecture eliminates external data sharing, satisfying HIPC's data sovereignty requirement without a Privacy Impact Assessment. The LLM_PROVIDER flag is the single mechanism to switch between a convenient cloud-assisted mode (for general use) and a compliant air-gapped mode (for health deployments). Same product. Same UI. Different egress profile.
